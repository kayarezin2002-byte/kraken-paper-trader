Create a new STRATEGY LAB for the Kraken Paper Trader.

The objective is to determine, from actual data, which combination of:

- entry rules
- LONG/SHORT scoring
- take-profit
- stop-loss
- trailing stops
- risk level
- timeframe
- market
- Elliott Wave alignment

produces the highest risk-adjusted returns.

Everything remains PAPER TRADING ONLY.

Do not connect real-money trading.

# 1. Core concept — parallel shadow strategies

Whenever the bot identifies a market opportunity, allow multiple experimental strategies to simulate what WOULD have happened.

These are called:

SHADOW STRATEGIES

They must NOT create duplicate real paper positions in the main account.

Example:

BTC produces ACTIVE LONG 4/6 at $X.

Main paper strategy may open one position.

At the same time Strategy Lab can independently simulate:

Experiment A — 0.3% TP / 0.25% SL  
Experiment B — 0.5% TP / 0.3% SL  
Experiment C — 0.75% TP / 0.4% SL  
Experiment D — trailing exit  
Experiment E — Elliott aligned only

All experiments use the same underlying market data.

# 26. Preserve all raw experimental data

Do not only store aggregate statistics.

Store sufficient information about each signal/trade so experiments can be recalculated later as the Strategy Lab develops.

Avoid deleting losing strategies or losing trades.

Negative results are important.

# 27. PERFORMANCE

The Strategy Lab must not cause the application to become slow.

Do not run hundreds of redundant indicator calculations.

Reuse cached candles, indicator values and signals wherever possible.

One market observation should feed multiple experimental calculations.

# 28. PAPER MODE ONLY

No real-money execution.

No exchange API keys.

No automatic transition from Strategy Lab to real trading.

The purpose is to discover whether we have a repeatable statistical edge before considering anything else.
